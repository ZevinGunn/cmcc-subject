> 你日常只需记 4 条命令。

---

## 一、一句话速查

| 我想 | 命令 |
| --- | --- |
| 启动全部服务（电脑重启后/一键拉起） | `bash ~/CMCC-PROJECT/_部署方案/start-all.sh` |
| 关闭全部业务服务（保留管理后台） | `bash ~/CMCC-PROJECT/_部署方案/stop-all.sh` |
| 改了某项目代码，重新构建+重启 | `bash ~/CMCC-PROJECT/_部署方案/rebuild.sh <项目名>` |

| 打开项目管理后台 | `https://project.1008086.xyz/` |

> Claude Code 命令前加 `!`，例如：`! bash ~/CMCC-PROJECT/_部署方案/start-all.sh`

## 三、改完代码怎么重启（按项目）

```bash
# 改了 cookie-app 的代码
bash ~/CMCC-PROJECT/_部署方案/rebuild.sh home

# 改了 bj-cmcc-qy 的代码
bash ~/CMCC-PROJECT/_部署方案/rebuild.sh rights

# 改了 qqt 的代码
bash ~/CMCC-PROJECT/_部署方案/rebuild.sh qqt

# 改了 cmcc-notice / arpu / qqtlocal（无构建步骤）
bash ~/CMCC-PROJECT/_部署方案/rebuild.sh notice
bash ~/CMCC-PROJECT/_部署方案/rebuild.sh arpu
bash ~/CMCC-PROJECT/_部署方案/rebuild.sh qqtlocal

# 全部重新构建 + 重启
bash ~/CMCC-PROJECT/_部署方案/rebuild.sh all
```

**只改后端不改前端**：直接 `pm2 restart <服务名> --update-env`，不必走 rebuild。

**只改 nginx 配置**：`sudo nginx -t && sudo nginx -s reload`

## 四、直接用 pm2 命令的速查

```bash
pm2 status                         # 看 6 个服务
pm2 logs cookie-app --lines 50     # 看日志
pm2 logs cookie-app --err          # 只看错误日志
pm2 restart cookie-app             # 重启某个
pm2 restart cookie-app --update-env # 重启+重读 .env
pm2 stop cookie-app                # 停止某个
pm2 start cookie-app               # 启动某个（从清单）
pm2 delete cookie-app              # 删除某个
pm2 monit                          # 实时监控
```

## 五、关闭服务的几种姿势

```bash
# 全部业务项目停（保留 project-manager 和 cloudflared）
bash ~/CMCC-PROJECT/_部署方案/stop-all.sh

# 全部业务项目停 + 同时停 cloudflared（外网完全不通）
bash ~/CMCC-PROJECT/_部署方案/stop-all.sh --with-tunnel

# 只停 cookie-app
pm2 stop cookie-app

# 只停 nginx
sudo brew services stop nginx

# 只停 PG（容器）
cd ~/CMCC-PROJECT/免登录进入全球通/cookie-app && docker compose stop
```

## 六、开机自启状态

| 组件 | 自启方式 | 是否已设 |
|---|---|---|
| nginx | brew services + LaunchAgent | ✅ |
| Docker Desktop | GUI 勾选 "Start when sign in" | **你检查一下** |
| Postgres 容器 | docker compose `restart: unless-stopped` | ✅ |
| PM2 | launchd + `pm2 save` | **跑 setup-autostart.sh** 后 ✅ |
| cloudflared | LaunchDaemon | ✅ |

如果重启 Mac 后某个没起来：

| 没起的 | 应急启动命令 |
|---|---|
| Docker / PG | `open -a Docker` 等 30 秒 |
| nginx | `sudo brew services start nginx` |
| PM2 | `pm2 resurrect` 或 `bash start-all.sh` |
| cloudflared | `sudo launchctl load -w /Library/LaunchDaemons/com.cloudflare.cloudflared.plist` |

或者最简单：

```bash
bash ~/CMCC-PROJECT/_部署方案/start-all.sh
```

会判断每一项的状态，没起的拉起来，已起的跳过。

## 七、有问题怎么查

1. **本机能开但浏览器打不开**：`bash ~/CMCC-PROJECT/_部署方案/healthcheck.sh`，看哪一环 ✗
2. **某域名 502**：`pm2 logs <对应服务名> --lines 50`，看后端报什么
3. **登录失败/数据库报错**：`pm2 logs cookie-app --err --lines 50`
4. **cloudflared 没接通**：`sudo tail -50 /Library/Logs/com.cloudflare.cloudflared.out.log`

```
├── start-all.sh            # 一键启动全部
├── stop-all.sh             # 一键关闭全部

├── setup-autostart.sh      # 一次性：设置 PM2 开机自启
└── 运维手册.md             # 本文档
```
