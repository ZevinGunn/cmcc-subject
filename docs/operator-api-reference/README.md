本次盘点包含 **400个自有实现候选文件、70个HAR、833个去重地址/能力码条目**，其中北京权益24种能力码。313条具有源码请求/动态分发/配置步骤证据，545条有HAR证据；两者存在重叠。数字包含历史端点、页面及配置，不能解释为833个接口全部可用。

参数表中的“实现传入”不等于运营商正式规定的“必填”；响应字段是历史样本/实现读取字段。未知项明确标注，不补造密钥或成功返回。个人Cookie、Token、验证码、服务密码、卡券、数据库主密钥和实例私钥均不收录。公开客户端固定协议常量及动态凭据的取得/使用方式见02。

推荐阅读示例：云盘短信登录 → 获取Authorization与routerInfo → 按toSourceId签发业务短票 → 目标站换会话 → 查询目标业务。全流程见01第4节，密码封装见P03/P04；不要将云盘Authorization直接当全球通access_token。
