# 本地权益订购项目设计开发文档

目标：开发一个仅本地使用的 Vue3 权益订购工具，支持输入商品/权益 id 或 code、手机号、验证码，完成权益解析、发送短信和确认订购。

## 一、产品范围

首版功能：

1. 输入 `skuId` 或预设 `code`。
2. 点击解析权益：如果输入的是 `code`，从 layout JSON 提取 `vipSkuId`；如果输入的是数字，直接作为 `skuId`。
3. 查询 SKU 类型，展示 `skuType/vipLevel/provinceCode/needEquity`。
4. 输入手机号，点击发送验证码。
5. 输入短信验证码，点击确认订购。
6. 展示原始响应、业务结果、错误原因。
7. 支持配置 `channelCode`、`referer`、`receipt/receiptModule`、`operDfp`。
8. 本地保存常用商品配置，不保存验证码，不默认保存手机号。

暂不做：

- 批量订购。
- 绕过平台风控。
- 自动破解验证码。
- 保存 HAR Cookie 或复用他人登录态。

## 三、后端 API 设计

### 1. 查询商品配置

```text
GET /api/products
```

返回本地 `data/products.json`：

```json
[
  {
    "code": "bojinyear",
    "name": "铂金会员年包",
    "skuId": "77626",
    "channelCode": "P00000139704",
    "referer": "bojinyear",
    "receipt": true,
    "receiptModule": true
  }
]
```

### 2. 解析权益 code

```text
GET /api/layout/resolve?code=bojinyear
```

后端处理：

1. 拼接 `https://res.coc.10086.cn/res/cdn/coc1/fixedPath/production.rightsmarket-h5-canvas.online.layout.{code}.json?tes={Date.now()}`。
2. 拉取 layout JSON。
3. 遍历 `instanceList`，解析每个 `instance.specify`。
4. 找到 `name === "Rights-PictureMemberOrderComp"` 或含 `vipSkuId` 的组件。
5. 返回页面信息、订购图、规则名和 `skuId`。

返回：

```json
{
  "code": "bojinyear",
  "name": "铂金会员年包",
  "title": "铂金会员年包",
  "skuId": "77626",
  "referer": "bojinyear",
  "orderImg": "https://res.coc.10086.cn/res/cdn/coc1/...",
  "rules": [
    "未订购铂金会员年包（含铂金、半年及年包优惠版）",
    "已订购铂金会员年包（含铂金、半年及年包优惠版）",
    "铂金会员年包-限制省份"
  ]
}
```

### 3. 查询 SKU 类型

```text
POST /api/sku/type
```

请求：

```json
{"skuId":"77626"}
```

后端请求：

```text
POST https://dev.coc.10086.cn/coc3/coc3-market-member/api/member/getSkuType
```

返回透传运营商接口的 `code/message/data/success`，前端展示 `skuType`、`vipLevel`、`provinceCode`、`needEquity`。

### 4. 发送验证码

```text
POST /api/sms/send
```

请求：

```json
{
  "phone": "13800138000",
  "skuId": "77626",
  "code": "bojinyear",
  "channelCode": "P00000139704"
}
```

后端处理：

1. 根据 `code` 补齐商品配置。
2. 校验手机号和 skuId。
3. 生成：
   - `receivers = aesZeroEncrypt(phone, "a4jdiq597p3gls0r")`
   - `skuId = aesZeroEncrypt(`${skuId}_${Date.now()}`, "72fc912ce498430d")`
4. 调用 `qwSendSmsCode`。
5. 返回解码/透传后的响应。

### 5. 获取 c1 token，可选

```text
GET /api/risk/c1?code=bojinyear&channelCode=P00000139704
```

后端请求：

```text
GET https://yxfk.market.chinamobile.com:8081/mgt/decision-engine/udid/c1?
```

首版只作为诊断/预留接口，不默认阻断订购流程。

### 6. 确认订购

```text
POST /api/order/direct
```

请求：

```json
{
  "phone": "13800138000",
  "smsCode": "123456",
  "skuId": "77626",
  "code": "bojinyear",
  "channelCode": "P00000139704",
  "operDfp": null
}
```

后端处理：

1. 生成订单字段：
   - `smsCode = aesZeroEncrypt(smsCode, "a4jdiq597p3gls0r")`
   - `phone = aesZeroEncrypt(phone, "a4jdiq597p3gls0r")`
   - `m1 = reverse(base64(phone))`
   - `s1 = reverse(base64(smsCode))`
   - `m2 = md5(phone + "AizkkwOAWRVihbCs" + m1)`
   - `s2 = md5(smsCode + "AizkkwOAWRVihbCs" + s1)`
2. 组装 directOrder 请求体。
3. 调用接口。
4. 返回接口响应。

### 7. 可选：商品详情

```text
POST /api/product/detail
```

请求：

```json
{"skuId":"77626"}
```

用于展示商品名、资费、说明。因为 HAR 没记录该请求的请求参数细节，开发时先从页面存档和在线接口试探确认。

## 四、核心代码模块

### `crypto.js`

需要实现：

```js
export function aesZeroEncrypt(plain, key, iv = key)
export function aesPkcs7Encrypt(plain, key, iv = "0123456789ABEDEF")
export function reverseBase64(value)
export function buildOrderProof(phone, smsCode)
```

注意：

- `aesZeroEncrypt` 必须使用 CBC + ZeroPadding。
- 输出必须是 Base64。
- `phone/smsCode/skuId` 统一按字符串处理。

### `cocClient.js`

职责：

- 设置 `Origin`、`Referer`、`User-Agent`、`Content-Type`。
- 请求 COC 接口。
- 解码 base64 响应或直接解析 JSON。
- 统一错误格式。

基础配置：

```js
BASE_URL=https://dev.coc.10086.cn
PAGE_REFERER=https://dev.coc.10086.cn/coc3/canvas/rightsmarket-h5-canvas/online/{referer}?channelCode={channelCode}&pageRecorded=true
LAYOUT_URL=https://res.coc.10086.cn/res/cdn/coc1/fixedPath/production.rightsmarket-h5-canvas.online.layout.{code}.json
```

### `layoutResolver.js`

职责：

- 判断输入是 `skuId` 还是 `code`。
- 拉取并解析 layout JSON。
- 从 `Rights-PictureMemberOrderComp` 的 `specify.vipSkuId` 提取 `skuId`。
- 提取页面名、订购图和规则名，给 Vue 页面展示。

## 五、前端页面设计

单页工具即可，主界面分 5 个区域：

1. 权益区：输入 `code/skuId`，选择预设商品，按钮为“解析权益”。
2. 预检区：展示名称、skuId、channelCode、规则、SKU 类型，按钮为“查询 SKU 类型”。
3. 手机区：输入手机号，按钮为“发送验证码”，成功后 60 秒倒计时。
4. 订购区：输入验证码、`operDfp` 可选值，按钮为“确认订购”。
5. 结果区：按阶段展示 layout、skuType、sms、order 的结果码、消息和原始响应。

推荐表单字段：

```text
权益 code / skuId：bojinyear
channelCode：P00000139704
selfChannelCode：P00000139704
referer：bojinyear
手机号：用户手动输入
验证码：用户手动输入
operDfp：可空
```

交互状态：

- 发送中、订购中禁用按钮。
- 验证码发送成功后启动倒计时。
- 订购结果按 `resultCode/code` 判断成功或失败。
- 敏感字段只在请求时进入后端，不在 localStorage 保存。
- 商品图 `orderImg` 只作为辅助展示，不影响订购请求。

7. 实现 Vue3 前端单页工具。
8. 本地联调：解析权益、查询 SKU 类型、发送验证码、输入真实验证码提交订购。

## 七、验证方案

自动验证：

- `reverseBase64(reverseBase64(phone) reversed back) == phone`
- `bojinyear` layout 可解析出 `skuId=77626`。
- `getSkuType` 可返回 `success=true` 或可诊断错误。
- `skuId` 加密长度/格式与 HAR 近似。
- 请求体字段完整性测试。

人工验证：

1. 打开本地页面。
2. 输入 `bojinyear` 或 `77626`。
3. 点击解析权益并确认得到 `skuId=77626`。
4. 点击查询 SKU 类型。
5. 输入本人手机号发送验证码。
6. 输入验证码提交。
7. 预期响应：
   - 已订购/互斥：返回业务冲突类结果，说明链路打通。
   - 成功：返回订购成功消息。
   - 风控失败：进入增强版风控 token 方案。

## 八、风险与边界

- 短信验证码和手机号属于敏感信息，后端日志必须脱敏。
- 不应内置 HAR Cookie。
- 不应做批量高频请求。
- 商品是否可订、资费和互斥规则由运营商接口实时决定，本地工具只负责提交本人明确输入的订购请求。

## 九、待你确认的开发方案

建议首版按“简化模式”开发：

- 不集成 Playwright 风控采集。
