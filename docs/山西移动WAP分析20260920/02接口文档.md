# 山西移动 WAP 接口文档

版本 1.0　分析基准 2026年9月20日　适用读者 接口开发 联调与测试

本接口参考记录 307 个可识别的接口地址或引用，保留地址大小写、历史拼写、调用函数、请求方法、加密开关与证据位置。它是前端和请求样本反向整理的契约，其中未获明文或缺少调用页面的字段以待确认标记，不视为服务方正式接口规范。

## 1 服务地址与契约边界

| 项目 | 值或约束 |
| --- | --- |
| 抓包主机 | https://wap.sx.10086.cn |
| act 页面目录 | /h/act/ |
| 主包相对 API | rest/v1/…；在 act 文档目录下解析为 /h/act/rest/v1/… |
| market 登录 API | /h/market/rest/v1/wapLogin/login 与 sendSmsCode，HAR 独立观察 |
| 例外路径 | rest/smartshop/userRest/mini/miniRoutScheme；/h/rest/v1/operateCSDdata/spageOperationCSDRest |
| 主体格式 | HAR 中 POST 为 application/json;charset=UTF-8 |
| 成功判定 | 常见 retCode=0000 或 parseInt(retCode)=0；各业务仍需单独确认 |
| 当前材料未确定 | 服务端版本、完整错误码、限流、会话有效期、幂等、分页和字段必填规则 |

所有 GET、POST 的方法保留源码声明。catalog 中“未定”表示只有字符串引用，不能擅自按 POST 生成调用。相同名称在 act 和 market 下属于不同地址，不能合并推断契约。部分接口名称带 Test 或 Manager，只能证明前端有引用，不能认定测试环境或管理权限已经隔离。

## 2 公共请求与响应

### 2.1 请求头

| 请求头 | 证据与用途 |
| --- | --- |
| Content-Type | HAR 为 JSON；勿用导出器的 params 数组重建表单 |
| cookieid | 主包默认设置 wapapp |
| E-A-K | 每请求 AES 密钥的 RSA 加密结果，十六进制；6 个加密样本长度均为 512 |
| E-T-K | 毫秒时间戳；源码用当前时间生成 |
| E-S-K | HMAC-SHA256 摘要，64 位十六进制 |
| restParams | fchama.httpReady() 的结果，属于公共采集或上下文信息，不能当作 AES 密钥 |
| Content-M-URL | YWKJ.getHeader() 提供的页面上下文，失败时回退当前页面 URL |
| Content-M-CODE | YWKJ.getHeader() 提供的 uuid；不得写死为 HAR 值 |
| Cookie | 捕获到会话、终端和统计相关 Cookie；认证依赖的最小集合未确定 |
| QcYzT7yx | HAR 中出现的动态头；当前未完成生成逻辑归因，不能用固定值替代 |
| Origin 与 Referer | 浏览器上下文，不能据此推断服务端仅依赖这两个头授权 |

### 2.2 统一补入字段

| 明文字段 | 来源 | 适用条件 |
| --- | --- | --- |
| couponsBusiName | 当前路由 meta.title | 公共拦截器，对非 text 响应类型调用补入 |
| businessCode | 页面路径到 busiId 的映射 | smsver/sendSmsCodeNew，匹配 goldExg 等 5 个路径 |
| uuid 与 busiType | busiSms-uuid 和 busiSms-type Cookie | Dj/6 名单，含 qqt5ga/submitPrcOrder |
| regFrom | 固定 JTST | /Htz 判断名单，不能全局添加 |
| wtAcId 与 wtAc | Vuex 活动渠道状态 | ybWN 判断名单，不能全局添加 |

页面传入空对象不代表线上业务明文就是空对象。必须完成补字段，再进行 JSON 序列化、加密和签名；对密文或序列化后的明文进行二次修改会造成契约不一致。

### 2.3 报文外层

加密请求为 {"encryptInStr":"<IV_HEX><AES_CIPHERTEXT_HEX>"}。加密响应为 {"secretOutId":"0","encryptOutStr":"<IV_HEX><AES_CIPHERTEXT_HEX>"}；响应 secretOutId 等于字符串 -1 时，前端直接 JSON.parse(encryptOutStr)。其他值在此版本前端统一进入解密分支，并未按 secretOutId 查找密钥。

常见业务响应字段为 retCode、retMsg、data，部分接口含顶层 uuid、detail_msg 或业务字段。它们并不构成所有接口均遵守的强制 schema。5G-A 查询兼容顶层和 data 内的 gBrandLevel；短信组件也兼容部分顶层及嵌套字段。

### 3.1 获取 RSA 公钥

POST /h/act/rest/v1/rsakey/getRsaPubKey。HAR 条目 6 的实际请求体为 {}，响应为明文 JSON。data 为十六进制 DER 公钥，解析结果 RSA 2048 位，指数 65537。其他响应字段含 retCode、retMsg、detail_msg、uuid。不要把 RSA 公钥当作 AES 解密密钥。源码封装本身仍经过公共字段补入逻辑，HAR {} 与当前源码可能有调用时机或来源差异，不能据此认定 couponsBusiName 为服务端必填。

### 3.2 广告配置

POST /h/act/rest/v1/businessTree/adInfoQry。请求结构为 encryptStr 和 secretid，采用独立 DES 协议；本样本解密的业务请求为 {"appId":"115"}，secretid 为空。响应结构为 eStr、sid，eStr 解密为含 retCode、retMsg、data 的 JSON，data 下含 AD_INFO_LIST。广告图片和跳转目标属于运营配置，不等同于业务 API。证据 APP 2397 至 2419 与 HAR 条目 4。

### 3.3 market 短信与登录

POST /h/market/rest/v1/wapLogin/sendSmsCode，HAR 条目 27；POST /h/market/rest/v1/wapLogin/login，HAR 条目 26。两者均含 encryptInStr 和 E-A-K、E-T-K、E-S-K，响应为 secretOutId、encryptOutStr。登录页分包未收录，且抓包缺少请求关联 AES 密钥，因此手机号、验证码、密码、loginType 等明文字段及成功结果均不应猜填。后续需在本人账号和受控测试环境下采集明文字段结构与脱敏业务响应。

## 4 已还原的核心明文契约

以下字段是前端实际构造或读取的字段，不能把“前端传入”直接解释为“服务端必填”。字典、长度限制、错误枚举仍以服务端契约为准。

### 4.1 act 登录态检查

POST rest/v1/wapLogin/checkLogin，desRest=true，公共函数 checkLoginNew。SSO_LOGIN 场景加密前的主体示意如下。

```json
{
  "pubInfo": {"busiType": "SSO_LOGIN"},
  "busiInfo": {},
  "couponsBusiName": "全球通5GA加速权益"
}
```

其他分支：ZYT 映射为 WISE_MED_LOGIN，busiInfo 加入 localStorage 中的 uid 与 parkCode；WISE_CITY_LOGIN、WISE_PARK_LOGIN、ENTERPRICE_LOGIN、GOLD_MANAGE_LOGIN、ASSIST_MANAGE_LOGIN、SMS_MANAGE_LOGIN 添加业务类型和 uid。成功时 SSO_LOGIN 读取 data.phone_no，管理类分支读取 data.phoneNo。证据 COMMON 11706 至 11755；HAR 条目 8 只佐证地址及加密外层。

### 4.2 act 令牌登录

POST rest/v1/wapLogin/login，desRest=true，函数 wapLogin。公共认证代码构造以下字段。

| 字段 | 类型或示例 | 来源 |
| --- | --- | --- |
| pubInfo.loginSourceCode | WX 或 BROWSER | User-Agent 场景判断 |
| pubInfo.loginType | token | 固定业务类型 |
| pubInfo.token | 字符串 | 统一认证 SDK 的 token，样本不保留 |
| pubInfo.userinformation | SDK 返回值 | 原始属性名为 userInformation，转发字段为小写 i |
| pubInfo.busiType | SSO_LOGIN 等 | 调用业务类型 |
| busiInfo.parkCode | 条件字段 | 医疗业务分支的本地上下文 |
| couponsBusiName | 字符串 | 公共层补入 |

SSO_LOGIN 成功分支读取 data.custInfo.phoneNo。该契约不能直接复用于 market 短信登录。另有 uniTokenValidate4Wap 接口直接接收 token 和 userInformation，字段大小写不同。

令牌获取前，公共模块调用 ywAuth.getSign，参数 appid=300011883695、version=1.2；将结果作为 presign 提交 rest/v1/getRsaSign，再把服务端返回 data 作为 sign 传给 ywAuth.getTokenInfo。后者使用 appId 和 version，以及 authPageType、expandParams、isTest 等选项。这里的 presign/sign 属于统一认证 SDK 的协议；服务端签名算法、密钥和有效期没有在前端中给出，不应与 E-S-K 的 HMAC 混为一谈。证据 COMMON 11792 至 11824。

### 4.3 全球通资格查询

POST rest/v1/qqt5ga/qryUserQualification，desRest=true，函数 qqt5gaQryUserQualification。页面调用参数为 {}，公共层追加 couponsBusiName。成功时读取 gBrandLevel 或 data.gBrandLevel；源码识别 0000、900004、900005、900006、900010，通用层识别 999999。没有字段证据表明必须在请求体再次传入 phoneNo。

### 4.4 敏感业务判断

POST rest/v1/sensitive/qryTag，desRest=true。输入 busiType，例如 QQT5GA_SMS；组件读取 data.isSensitive 或顶层 isSensitive，Y 进入敏感模式，其他或查询异常在此版本组件中进入普通模式。服务端是否允许这种回退需专项确认，不能把前端行为解释为风控豁免。

### 4.5 业务验证码发送

POST rest/v1/smsver/sendSmsCodeNew，desRest=true，函数 getSmsCodeSmsver。业务短信与 market 登录短信是不同接口、不同业务凭据。

| 字段 | 前端来源与 5G-A 示例 |
| --- | --- |
| channelId | 由渠道判断获得，普通网页默认 llwap0 |
| busiType | QQT5GA_SMS |
| busiName | 全球通5GA加速权益 |
| prodDesc | 5GA加速权益 |
| effDate | 立即生效 |
| sendType | 字符串 2 |
| prcId | BCAT5075 |
| actType、busiId、actId、meansId | 页面初始化选项；此页面未提供时为空字符串 |
| isSensitive | 敏感模式传 Y；普通分支未显式传入 |
| couponsBusiName | 公共层补入 |
| businessCode | 仅匹配公共路径名单时补入；5G-A 不在该 5 项名单中 |

普通成功分支读取顶层 uuid。敏感成功分支读取顶层或 data 内的 uuid、pos1、pos2、val1、val2，并校验位置及固定数字格式。响应的必填条件、短信有效时间及服务端限流需要正式定义。

### 4.6 业务验证码校验

POST rest/v1/smsver/chkSmsCodeNew，desRest=true。输入 uuid、busiType、smsCode；敏感模式另传 isSensitive=Y。普通 smsCode 为 6 位数字，敏感模式为拼合后的 8 位数字。成功后前端写入短信 Cookie 并触发 changeBusiSms。保留验证码作为字符串，防止丢失开头的 0。

### 4.7 全球通权益订购

POST rest/v1/qqt5ga/submitPrcOrder，desRest=true。页面仅传 {}，最终加密前主体至少由公共逻辑构成以下结构；示例为源码重建，不是真实抓包明文。

```json
{
  "couponsBusiName": "全球通5GA加速权益",
  "uuid": "<短信业务凭据>",
  "busiType": "QQT5GA_SMS"
}
```

BCAT5075 出现在短信初始化中，页面提交对象没有显式携带 prcId，不应擅自添加为“必填订购参数”。HTTP 返回之后，公共层清空短信凭据 Cookie；业务层依据 retCode 展示成功或失败。接口没有抓包验证，订单号、权益生效信息、去重机制和状态查询接口仍需补充。

### 4.8 弹窗 提示与公共查询

app/popup/config、tip/qryAvaliableTip 已在 HAR 中出现，且源码均启用 desRest。配置接口传入 pageUrl，成功后读取 data.bannerShow、dialogsShow、blacklistInfo、popupInfo；popupInfo 按 showType=POPUP 或 FLOAT 区分展示。行为接口 app/popup/behavior 传入 id=1、behaviorType 和 pageUrl，源码可见 VIEW 分支，但完整枚举待确认。

tip/qryAvaliableTip 传入 YWKJ 相关工具取得的 userId 和空字符串 tipBusiType，读取 data 作为提示配置；tip/submitShowLog 传入 tipId、userId、tipBusiType。提示组件读取 id、tipTitle、tipContent。证据 APP 4477 至 4495、4560 至 4583。

GET rest/v1/cust/level 与 GET rest/v1/robot/robotOnline 为少量 GET 声明，源码 data 的使用不等于查询参数契约，应联调核定 Axios 实际序列化。

### 4.9 充值公共组件

POST rest/v1/payfee/qrybank 传入 phoneNo，成功读取 data 为支付渠道列表，条目包含 payWay。POST rest/v1/payfee/validphone 传入 phoneNo、targetFee、pay_way；targetFee 在该组件中由输入金额乘以 100 后转为字符串，响应读取 data.isValid。单位换算只能用于该组件的契约，不可套用于所有账单与支付接口。

POST rest/v1/payfee/createordernew 在此调用中传入 phoneNo、tradeId、payWay、returnUrl、orderId；phoneNo 与 payWay 已分别进行 DES 字段加密，tradeId 和 orderId 来自同一个外部 orderIdB。成功读取 data.redirectUrl 和 data.orderId，组件把 redirectUrl 的查询参数转成表单再提交到其中的网关地址，代码对 CustomParam、SignValue 有专门拆解。该网关地址属于运行时返回值，材料无法给出固定生产网关契约。证据 APP 4977 至 5060。没有观察到对应真实支付请求。

## 5 其他业务接口使用约束

已订业务使用 userorderinfo/qryUserOrderInfo、qryUserOrderDetail；退订为 prod/unSubScribeOrder。金币兑换涉及规则校验、库存和确认，权益分配涉及 checkRole、queryGroupEquity、distribute 与 exchange2BApply/exchange2C。支付相关 createorder、createordernew、makeOrder、createpayorder 属于不同契约，不可通过同名参数互相替换。

这些接口大多只有参数透传封装。除本文件明确列出的字段外，请求业务字段、响应字段、类型、长度、必填性、枚举、分页、订单号与错误码均待调用页面或服务端文档补齐。全量清单逐项标注证据，避免“没有读取到参数”被误解为“接口无需参数”。

## 7 第三方与非业务请求

业务 API 清单不把图片、字体、SDK 脚本、SPA hash 路由或广告跳转链接计入接口数。补充依赖包括统一认证 SDK、YWKJ 容器能力、微信分享 SDK、集团 APP cmcc.js、jiguang.coc.10086.cn 的采集地址、全球通权益外链。绝对 URL 及运营配置中的跳转项另存 外部地址与依赖.json，保留类别，剔除查询参数值，避免传播会话信息。

混淆脚本 94ftzVHOoJ5z.1058d2a.js 与页面 $_ts 初始化共同出现；HAR 还包含动态头及不透明 Cookie。可以确认存在额外环境依赖，但不能仅凭形态确定厂商、内部算法或全部服务端校验规则。

另有动态地址封装 gestStaticRes(url)，指定 responseType=text、未显式设置 method，位于 APP 7327 至 7334；采集模块 sendInfo 以 POST 向 this.url 上报，位于 APP 5783 至 5790。由于地址来自运行时输入，它们不增加固定地址清单的计数。依赖包内还出现 trace.hjq.komect.com/TRACEProbeService/accept 等 SDK 地址和测试主机字面量，已归入外部地址文件；打包存在不等于当前页面实际调用。
