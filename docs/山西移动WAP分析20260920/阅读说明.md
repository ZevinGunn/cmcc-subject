# 山西移动 WAP 分析文档包

建议按产品说明、接口文档、认证加密与实施方案的顺序阅读。三个主题均提供可编辑 Word 和 Markdown。材料涉及 307 个接口地址或引用、92 条路由；其中仅 8 个接口在 HAR 中出现。全部关键结论区分源码、抓包与待验证内容。

| 文件 | 用途 |
| --- | --- |
| 01产品功能说明 | 功能全景、用户流程、5G-A 规则、验收、全量路由 |
| 02接口文档 | 公共契约、HAR 全部接口、核心字段、307 项完整接口目录 |
| 03认证加密与实施方案 | AES RSA HMAC DES、会话、验证、架构与实施验收 |
| 04接口字段与证据逐项参考.md | 每个接口的函数、已见字段、精确来源、未确定项 |
| 05证据与范围索引.md | 输入哈希、证据分级、统计口径与待补材料 |
| 接口清单.json 与 csv | 全量可检索接口数据、调用点字段及行号 |
| 页面路由清单.json 与 csv | 92 条页面路由及分包缺失状态 |
| OpenAPI草案.json | 285 个有方法证据的路径，22 个未定路径单列；schema 未完善 |
| HAR脱敏摘要.json | 全部 8 个业务请求的脱敏外层与时间信息 |
| 外部地址与依赖.json | SDK、广告目标和其他静态地址，去掉查询值 |
| 离线验证结果.json | 独立密码实现交叉验证的结果与边界 |

本包不附原始抓包或会话凭据，不执行登录、发短信、订购、退订或支付。普通接口的“普通”表示未启用统一 desRest，加密仍可能在调用处或单独字段完成。OpenAPI 为证据草案，不能直接作为生产接口保证。
