# CMCC OPS V2 页面与状态验收清单

本清单用于产品、设计、前端和测试共同验收，不替代 API 测试。

## 全局

- [ ] V1 路由、数据和任务逻辑保持不变。
- [ ] `/v2` 可由 `VITE_UI_V2_ENABLED` 独立关闭。
- [ ] V1/V2 切换尊重直接访问 URL，不产生重定向循环。
- [ ] 管理端、用户端和管理员登录有清晰不同的产品身份。
- [ ] 所有页面具备加载、空、错误、无权限和正常状态。
- [ ] 错误不会在用户读完前自动消失。
- [ ] 任务创建后可离开页面并从任务中心找回。
- [ ] 原始 Cookie、Token、App CK 不在列表默认展示。
- [ ] 320px 宽度无主流程横向溢出、遮挡或按钮文字截断。

## 工作台

- [ ] 健康、待处理和任务统计使用统一口径。
- [ ] 今日待办按影响程度排序。
- [ ] 点击待办进入正确页面并携带筛选。
- [ ] 运行中任务的进度、状态和预计时间准确。
- [ ] 无待办时不显示虚假的全绿评分卡。

## 账号中心

- [ ] 健康状态包含健康、即将到期、需重新登录、需维护、已失效、未知。
- [ ] 筛选统计与结果数量一致。
- [ ] 切换筛选后显示当前筛选与其他筛选的已选数量。
- [ ] 所有批量动作使用同一最终选择范围。
- [ ] 批量任务提交前显示任务、范围、依赖和账号数量。
- [ ] 账号详情可查看凭据状态，不默认显示原始值。
- [ ] 清除凭据、失效和永久删除使用不同文案与确认流程。
- [ ] 移动端使用摘要列表和全屏详情，不压缩桌面表格。

## 登录流程

- [ ] 添加账号和重新登录使用同一流程。
- [ ] 短信、App 扫码、云盘短信、Cookie/HAR 导入入口语义清楚。
- [ ] 短信发送和登录冷却在控件附近显示剩余时间。
- [ ] 扫码自动轮询、自动保存，不要求手动检查和补保存。
- [ ] 完成后自动校验能力并展示恢复结果。
- [ ] 失败展示可操作原因和 `requestId`。

## 任务中心

- [ ] 任务状态包含排队、执行中、成功、部分成功、失败、已停止。
- [ ] 已停止由 UI 适配层正确映射。
- [ ] 任务历史支持分页和筛选。
- [ ] 账号级明细支持分页、错误分组和重试失败项。
- [ ] 冲突任务解释禁用原因并链接到现有任务。
- [ ] 停止任务前展示已完成、执行中和未开始数量。

## 自动化计划

- [ ] 计划保存任务模板、范围、时区、并发和依赖配置。
- [ ] 下一次执行时间准确显示北京时间。
- [ ] 相同计划不会重叠运行。
- [ ] 跳过、失败和部分成功都有历史记录。
- [ ] SSPID、活动凭据不是仅存在于前端表单的无效配置。

## 权益活动

- [ ] 全球通签到、星动日、周三拼图和未领取 Token 独立统计。
- [ ] 活动结果与技术任务日志可互相跳转。
- [ ] “未领取”只计算已查询且明确未领取的账号。
- [ ] Token 导出显示导出、去重和跳过数量。

## 业务查询与退订

- [ ] 套餐与合约、宽带、商城业务的数据源命名清楚。
- [ ] 切换 Tab 和详情往返保留当前账号上下文。
- [ ] 退订前展示账号、业务、费用、合约限制和失效时间。
- [ ] 合约期内不可退订时不展示误导性的确认按钮。
- [ ] 短信验证码冷却与失败原因可见。
- [ ] 完成后生成可追踪的退订记录。

## 专属链接

- [ ] 链接列表同时展示账号、用户、通知、活跃和状态。
- [ ] 复制、二维码和通知配置集中在详情。
- [ ] 停用前展示关联账号数量。
- [ ] 当前后端清除凭据副作用在确认中明确展示。
- [ ] 停用不可使用普通删除确认或伪撤销 Toast。

## 用户与权限

- [ ] 注册、邀请码登录和管理员策略分区清楚。
- [ ] 用户权限来自正式 schema 和 migration。
- [ ] 修改权限、重置密码和停用用户写入审计日志。
- [ ] 普通用户无法访问其他链接的账号和任务。

## 日志与设置

- [ ] 日志读取接口分页、脱敏并受权限保护。
- [ ] 可按 `requestId/accountId/taskId/linkId` 查询。
- [ ] 配置变更写入审计日志。
- [ ] Worker 切换只影响新任务。
- [ ] 高风险设置需要二次确认。
- [ ] cleanup 接口在 V2 灰度前完成管理员鉴权。
