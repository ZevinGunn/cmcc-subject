# 北京电信本地助手

管理北京电信账号、无窗口服务密码登录和过期自动补登。界面适配 PC Web 与移动端 H5；独立青龙 Python 脚本保留在 `qinglong/`，网页版不显示青龙配置或任务记录页面。

## 本地运行

```sh
pnpm install
pnpm --filter ct189-local-backend exec playwright install chromium
pnpm run dev
```

工作台：http://127.0.0.1:5711；API：http://127.0.0.1:5710，默认仅监听本机。H5 指响应式网页，不会自动开放局域网访问或配置公网服务。

## 账号管理

- 添加、编辑备注与分组、启用/停用、删除账号及已保存的密码和本地会话。
- 号码/备注/分组搜索，登录状态与分组筛选。
- 多选检查登录、更新资料、关闭会话、分组、启停和删除。当前批次结果直接显示在账号列表下方，不读取历史任务列表。
- 批量导入：每行 `手机号#备注#分组`，不包含密码。每批最多 200 个；重复号码跳过，格式验证失败时整批拒绝。
- 列表使用掩码号码作为主标识，备注单独显示。1–32 位纯数字备注可能包含服务密码，旧备注自动清除，新备注不接受此格式。

查询资料先核验会话，必要时自动补登，再查询活动 310 和余额候选接口。部分失败保留返回结果并标注，HTTP 200 不等于业务成功。详情可展开最近查询结果；网页版不提供签到、领取权益按钮。

## 记住密码和自动补登

登录默认勾选「记住服务密码，过期自动补登」。只有密码提交成功且官网确认的号码与目标手机号完全一致后，才保存新密码；手动登录失败不会覆盖已有密文。取消勾选会删除该账号已保存的密码，即使本次登录未成功也不会保留旧密码。

服务密码通过 AES-256-GCM 加密，随机 IV，并绑定账号 ID。账号文件只保存密文；本机密钥单独保存在 `backend/data/credential.key`，权限 600。账号 API 不返回明文、密文或密钥，只返回是否已保存、补登状态等信息。浏览器不在 localStorage/sessionStorage 保存密码，也不会把已记住密码回填到输入框。

后台启动后检查可自动补登的账号，随后每 5 分钟检查一次；「检查登录」和「更新资料」也会按需检查。确认会话失效时，才使用已保存密码补登。不能核验官网响应时显示待核验，不因为网络或风控失败直接提交密码。

- 官网明确拒绝密码、号码不匹配，或密码提交/确认中断：暂停自动尝试，显示手动重新登录入口，避免反复提交。
- 后台在自动补登过程中意外退出时，下次启动暂停该账号的自动尝试，需手动重新登录。
- 匿名初始化失败：退避 15 分钟；密码请求不在一次登录中自动重放。
- 重新登录自动填入对应手机号并锁定，密码输入框始终为空，用户只需输入新的服务密码。成功后恢复自动补登并替换密文。
- 已停用账号不自动补登。手动关闭会话后暂停补登，重新手动登录才恢复。
- 凭据密钥丢失或密文损坏时要求重新输入密码。备份账号文件时需同时保留本机密钥。

自动补登仍需要联网；官网要求人工验证或风控拒绝时，不能保证自动通过。后台以无头 Chromium 执行官方页面动态脚本，不打开窗口、不跳转浏览器；`CT189_HEADLESS=false` 也不会启用可视窗口。

## 品牌和响应式界面

`frontend/public/telecom-logo.png`、`favicon.png`、`apple-touch-icon.png` 由用户提供的北京电信 5G 图片处理生成。主题区域采用同图淡化及渐变背景。PC 展示完整表格，H5 收起次要列；登录弹窗限制高度并独立滚动，手机输入字号避免自动缩放。

## 青龙独立脚本

[`qinglong/ct189.py`](qinglong/ct189.py) 与 [`qinglong/README.md`](qinglong/README.md) 保持独立，不依赖网页服务或共享网页密钥。环境变量 `CT189_ACCOUNTS` 每行 `手机号#服务密码#备注`，也支持 JSON 数组。

```sh
python3 ct189.py --tasks login
python3 ct189.py --tasks login,activity
```

当前支持登录和只读活动资格查询，签到、领取尚未接入。

## 数据与验证

`backend/data/accounts.json` 保存账号、凭据密文和内部操作结果，原子替换写入，权限 600；`backend/data/browser/` 包含 Cookie。上述运行数据与密钥均不提交 Git。`CT189_DATA_DIR` 可覆盖后端数据目录，测试使用临时目录。

```sh
pnpm test
pnpm build
# 前端启动后使用虚构账号和拦截响应验证 PC/H5：
pnpm --filter ct189-local-frontend test:browser
```

测试覆盖密码加密和账号绑定、自动补登及并发去重、密码错误后的停止和手动替换、网络故障、关闭/停用、API 保密，以及 1440/390/320 像素界面的交互。测试不执行真实签到或领取。当前项目无公网部署入口。
