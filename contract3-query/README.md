# 北京移动合约查询

统一查询二类合约、三类合约、低消方案对应全球通等级及网格通业务。支持关键词组合搜索、筛选、分页、CSV 导出，保留 ARPU 查询互通入口。项目管理中的服务 ID 为 `contract3`，PM2 服务为 `contract3-query`。

二类、三类及低消方案支持最低/最高价格（元，含边界）、价格升序/降序。优先采用明确的金额或低消承诺金额；缺少金额时识别名称中唯一的“元/档”价格及明确的折后价格，不将宽带速率、月份、年份视为价格。多档金额、仅给出起价或名称含多个不同金额且无法确定时，价格显示为 `-`，价格排序时放在最后，设置价格区间时排除。价格是源表中的金额或方案档位，不代表统一的月费口径。

价格条件与关键词、分类、等级及版本分区叠加，先筛选和排序再分页；表格标题旁显示全部匹配记录的总数。重置会清除价格条件，链接和 CSV 导出保留当前条件及顺序。网格通业务包含多个不同档位，暂不提供单一价格筛选。

三类合约和低消方案等级表支持按名称归纳的业务分类，包含吉祥号码、政企合约、信用购机、金币/AI豆、宽带/家庭融合、会员/权益、流量包、终端/设备、套餐/资费等。每项按规则优先级归入一个分类，未命中规则的归为“其他”；这些分类是站内查询辅助，不是源表官方分类。分类使用当前名称，删减区使用旧名称，分类计算不计入版本内容变更。分类可与三类 ID 前缀、全球通等级、价格和关键词组合，链接及 CSV 保留分类条件；二类沿用已有分类。

## 导入、验证与运行

导入器需要 Python `openpyxl`，参数指定上述四个文件所在目录：

```bash
npm run import:xlsx -- --source-dir '/实际源文件目录' --baseline before-20261105
npm run build
PORT=3002 npm start
```

仅更新网格通时加 `--grid-only`，不改动其他合约数据及对比基线：

```bash
npm run import:xlsx -- --source-dir '/实际源文件目录' --grid-only
```

`/api/health` 的 `gridLinks.available` 应为 `358`。原始链接文件缺失时，查询仍可使用，跳转明确返回 503；不得退回删参数后的错误地址。不要把原始链接或重定向响应头写入日志、提交或截图。

每次新一轮更新使用新的 `--baseline before-YYYYMMDD` 名称，以更新前的当前 JSON 保存基线；同名基线已存在时绝不覆盖，重复导入始终与同一旧版比较。基线在 `data/baselines/`，由对应数据文件 `meta.baselineFile` 引用。所有输入校验通过才更新运行数据。

服务直接发布 `public/` 静态文件，无需转译或打包；`npm run build` 执行服务与前端语法检查及完整回归测试，不生成另一套产物。历史 `.xls`、`.docx` 导入脚本保留用于旧格式溯源，不用于当前版本更新。

生产入口：`https://contracts.1008086.xyz/`，兼容入口：`https://contract3.1008086.xyz/`。

部署使用当前项目目录，验证并提交后仅重启 PM2 `contract3-query`。核验 `/api/health` 中的 `version`、记录数、`/api/catalogs` 对比数量及版本化 JS/CSS，不能只看 HTTP 200。

## 接口

- `GET /api/health`
- `GET /api/catalogs`
- `GET /api/contracts?type=2&q=关键词&prefix=111603&category=分类&page=1&pageSize=50`
- `GET /api/contracts?type=3&view=added|removed|changed|current&q=关键词`
- `GET /api/contracts?type=3&category=信用购机&prefix=111603`
- `GET /api/contracts?type=low&view=changed&grade=钻石卡&q=名称或策划ID`
- `GET /api/contracts?type=low&q=爱家&grade=金卡&minPrice=158&maxPrice=198&sort=price-asc`
- `GET /api/contracts?type=low&category=宽带/家庭融合&grade=金卡&minPrice=158&maxPrice=198`
- `GET /api/contracts?type=grid&q=业务ID或名称或档位`
- `GET /api/contracts.csv?type=2|3|low|grid&view=current|added|removed|changed&q=关键词`

`view` 缺省为 `current`，网格通仅有当前清单。无效视图回到当前清单。为兼容原三类接口，`type` 缺省仍为 `3`。差异清单支持同样的筛选、分页及导出，内容变更支持检索旧名称，CSV 同时提供变更前后内容。

`minPrice`、`maxPrice` 可单独使用，接受非负数且最多两位小数；非法区间返回 HTTP 400。`sort` 为 `price-asc` 或 `price-desc`，省略时保留源表顺序，同价格保持原顺序。JSON 的 `price` 为数值或 `null`，`total` 为分页前的筛选结果总数。CSV 接受相同参数。
