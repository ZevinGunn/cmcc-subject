# 权益订购本地工具

本项目是一个本地使用的 Vue3 + Node 工具，用于输入权益 `code/skuId`、手机号和短信验证码后，调用 COC 权益订购接口。

## 启动

```bash
npm install
npm run install:all
npm run dev
```

前端地址：

```text
http://127.0.0.1:5177
```

后端地址：

```text
http://127.0.0.1:3100
```

## 首版流程

1. 输入 `bojinyear` 或 `77626`。
2. 点击“解析权益”。
3. 点击“查询 SKU 类型”。
4. 输入本人手机号并发送验证码。
5. 输入短信验证码并确认订购。

## 说明

- 后端不会保存验证码，也不会默认保存手机号。
- 不内置 HAR Cookie。
- `operDfp` 首版可空，遇到风控失败时可手动填写或后续接入浏览器风控采集。
- 仅面向本人明确输入的单次订购操作。
