## 功能验证范围

- 六项自动化测试通过：导航与邀请码边界、站点 Cookie、HTML 错误、认证失效、注销后迟到响应。
- 桌面：三个工具切换、专属链接弹窗、错误链接拦截、800×600 和 1280×860 窗口适配；远程页面无 Node.js 和原生桥接权限。外部 HTTPS 使用系统浏览器，异步弹窗安全跳转通过。
- Android：安装启动、三个工具切换、弹窗关闭、横竖屏与安全区域测试通过；未发现应用未处理崩溃。空白跳转窗口数量有上限，并在关闭和退出时回收。
- 测试未发送真实短信，也未执行订购、退订、赠送或抽奖。真实账号完整业务流程及更多 Android 厂商设备兼容性仍需后续验证。
- 设计沿用 Apple 与产品界面技能的清晰层级、克制导航、系统字体和明确交互反馈，复用网站已有业务界面。

## 微信小程序边界

首版为原生页面，包含站点登录、账号摘要/权限、星巴克短信登录、卡券筛选和分类复制；不包含网页端全部运营商业务、扫码登录、周三互助、订购/退订。工程使用 `touristappid`，保留合法域名校验。注册后填写真实 AppID，配置 `home.1008086.xyz` 的 request 合法域名、类目与隐私声明，再通过开发者工具和真机联调；源码包不能直接作为可安装的小程序分发。

本次只新增客户端，不修改公网运行代码，因此未重启既有公网服务。源码、依赖锁定文件、构建与验证脚本保存于所属本地 Git 仓库；安装包与本机签名不提交。
