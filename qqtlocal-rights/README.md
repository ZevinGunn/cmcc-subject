# 全球通权益抢购助手 - 项目文档

## 1. 项目简介

本项目是一个**高性能、多语言支持**的本地自动化抢购工具，专为全球通权益（如名创优品代金券）抢购场景设计。项目采用 **前后端分离** 的架构，前端提供友好的可视化配置界面，后端通过 **Python FastAPI** 进行任务调度，并支持使用 **Python (AsyncIO)**、**Go** 或 **Java** 三种高性能执行引擎来执行具体的抢购任务。

**核心特性：**
*   **可视化配置**：通过 Web 界面轻松管理 Cookies、抢购时间、商品 ID 和并发策略。
*   **多语言引擎**：内置 Python、Go、Java 三种执行器，可根据需求切换，追求极致性能。
*   **高性能并发**：支持高并发抢购（Go/Java 模式下轻松支持 1000+ 并发），毫秒级响应。
*   **任务持久化**：任务配置自动保存，重启不丢失。
*   **一键启动**：提供自动化脚本，自动配置环境并启动服务。

## 2. 快速开始

### 环境要求
*   **操作系统**：macOS / Linux (Windows 需适配脚本)
*   **基础环境**：
    *   Python 3.8+
    *   Go 1.19+ (可选，仅 Go 模式需要)
    *   Java/JDK 11+ (可选，仅 Java 模式需要；macOS 只有 `/usr/bin/java` 但未安装 JDK 时不可用)

### 启动步骤
在项目根目录下，打开终端执行以下命令：

```bash
./run.sh
```

该脚本会自动执行以下操作：
1.  创建 Python 虚拟环境并安装依赖。
2.  检测并编译 Go Worker；若本机已安装可用 JDK 11+，同时编译 Java Worker。
3.  启动 Web 服务（默认端口 8000）。

启动成功后，请在浏览器访问：[http://localhost:8899](http://localhost:8899)

如需让其他设备通过域名访问，请确保服务绑定 `0.0.0.0:8899`，例如：

```bash
uvicorn backend.app:app --host 0.0.0.0 --port 8899
```

如果使用 `./run.sh` 启动，也可以直接设置：

```bash
QQT_HOST=0.0.0.0 QQT_PORT=8899 ./run.sh
```

## 3. 功能使用指南

### 3.1 获取 Cookie
由于项目专注于“抢购执行”，建议通过抓包工具或浏览器开发者工具（F12）获取目标网站（全球通权益页面）的 Cookie。
*   格式要求：每行一个账号的完整 Cookie 字符串。

### 3.2 创建抢购任务
在 Web 界面填写以下信息：
*   **任务名称**：任意备注名。
*   **Cookies**：粘贴抓取到的 Cookie，支持多账号（换行分隔）。
*   **商品ID**：目标抢购商品的 ID（例如名创优品默认为 `3566`）。
*   **执行器 (Executor)**：
    *   `Python (AsyncIO)`：适合一般并发，启动快，无需编译。
    *   `Go (High Performance)`：**推荐**，极低资源占用，超高并发。
    *   `Java (Multithreaded)`：适合 Java 环境成熟的机器；需安装 JDK 11+，后端会在日志中输出 Java/Maven 诊断，失败时自动降级 Python。
*   **运行模式**：通常选择 `concurrent`（并发模式）。
*   **并发线程数**：建议从 `10` 起步，10-30 个账号可试 `10-16`，30 个以上可试 `16-24`；最终以日志里的 `RTT p95`、最大 RTT 和成功率为准。
*   **调度类型**：
    *   `immediate`：立即执行一次。
    *   `date`：指定具体时间（如 `2025-01-01 10:00:00`）执行。
    *   `cron`：周期性执行（如每天 10 点）。

### 3.3 查看日志
任务执行后，可以在页面下方的“日志”区域输入 `job_id` 查看详细的执行日志，包括每个账号的抢购结果和服务器响应。

## 4. 技术架构与扩展

### 目录结构
```text
.
├── backend/            # Python 后端 (FastAPI + APScheduler)
├── web/                # 前端页面 (HTML/JS)
├── go-worker/          # Go 语言执行器源码
├── java-worker/        # Java 语言执行器源码
├── data/               # 任务数据存储 (JSON)
├── logs/               # 运行日志
└── run.sh              # 一键启动脚本
```

### 二次开发
*   **添加新执行器**：参考 `backend/app.py` 中的 `run_external_worker` 函数，只要新程序能接收 JSON 参数并输出日志到标准输出即可集成。
*   **修改抢购逻辑**：
    *   Python: 修改 `backend/qqt_mcyp.py`
    *   Go: 修改 `go-worker/main.go`
    *   Java: 修改 `java-worker/src/main/java/com/qqt/Worker.java`

- 登录体系已拆分成两张页面：`/login.html` 仅用于用户密钥登录，`/admin.html` 专门用于管理员登录与密钥治理，界面统一采用纯白+简洁平面风格。
- 控制台新增“一键清除全部账号”按钮，清空本地数据、停止任务并重置日志面板，方便重置环境。
- 实时日志面板新增“复制日志”功能，会将当前页面配置、账号清单、任务状态与详细日志一并导出到剪贴板，有助于后续分析与优化。
- 配置面板新增“每轮账号间隔”和“每轮账号数”选项，后端会在 5 次轮询中顺序错峰地分批发请求（默认每轮 5 个账号、间隔 10ms），确保所有请求都落在 10:00:00.050~0.150 的黄金窗口。
- 新增“🧪 一键测试”按钮，点击后系统会自动安排 1 分钟后的测试任务并根据账号数量调整轮询参数，日志会带【测试模式】前缀，方便你验证策略是否命中目标窗口。
- 新增“🚀 正式抢购”按钮，点击后会把目标时间固定为每天 10:00:00、将轮询参数调整到 20 个账号 / 每轮 4 个 / 间隔 20ms，并立即保存配置下发定时任务，适合每天直接启动正式跑量。
