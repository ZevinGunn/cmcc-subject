# 晋速办 1.1

山西移动本地业务操作台，地址 **http://127.0.0.1:4318**。本次资料对应的订购业务为**全球通 5G-A 加速权益 BCAT5075**，支持登录短信、验证码登录、业务内容/资格查询、普通或敏感业务短信验证、确认订购和结果核查。

页面使用用户提供的山西移动图标作为主题 Logo、PNG/ICO favicon 与 Apple touch icon，采用蓝绿渐变背景和顶部导航。业务条款、资格结果、验证码和最终确认保持独立呈现；未登录时可直接从业务卡片打开登录框。

## 使用

双击 `启动晋速办.command`，或执行 `node scripts/start.mjs`。

1. 点击“验证码登录”，填写手机号，阅读服务协议与隐私政策后获取登录短信。
2. 输入当次 6 位登录验证码。登录成功后展示脱敏号码。
3. 点击“查询业务内容”，查看资费、产品编码、条件、官方资格结果及查询时间。
4. 符合资格时点击“办理此权益”；提示“已默认享有”或“已办理”时，也可点击“仍尝试办理”。在弹窗中获取业务短信，敏感验证码由官方返回两位固定数字与位置，本地补齐后提交验证。
5. 核对号码、0 元资费和使用条件，勾选确认后提交。结果在“办理记录”中保存。

登录失败可选择“官方窗口登录”，完成后点击“同步官方登录”。官方窗口即使没有加载 Vue 登录表单，签名请求适配仍可独立工作；若官网要求人工验证，请在窗口完成。验证码和订购请求不自动重试。

“已订业务”继续使用官方 `/commserver/userBuss` 页面实际发出的查询，展示本次捕获的响应；其可用性依赖官方业务页面，不承诺覆盖所有分类与分页。业务内容查询与此列表是两个独立入口，失败不会清空已加载列表。

## 范围与验证边界

当前订购仅接入附件中有完整证据的 BCAT5075。实际资格以官方结果为准。“仍尝试办理”保留无需办理提示，允许用户主动经过短信验证与最终确认向官方提交，受理与否展示官方原始结果。该选项不解除本机已有成功或结果待核查记录的重复提交保护，也不放开资格过期、无资格或未知响应。其他商品、收费业务与退订没有足够接口契约，未作为可办产品开放。

2026-10-17 已验证官方实时公钥、签名请求及响应解密：新建空会话的登录检查返回 `777777 / 未查到用户登录信息`，资格查询返回 `999999 / 用户未登录`。未复用 HAR 中的账号、Cookie 或验证码。最初实测登录短信接口返回 `0000 / OK`，但用户未收到；对齐官方 SDK 环境头与登录路由标题后，22:40:34（北京时间）再次请求，用户确认此次短信已收到。随后使用用户当次提供的验证码登录，官方身份检查返回 `0000 / OK`，号码与本轮输入一致；业务资格查询返回 `900005 / 本权益您已默认享有，无需办理`。**真实登录短信到达、验证码登录与已登录资格查询已验证。** 未发送业务订购短信或真实订购，已订业务列表与订购链路仍未完成线上验收。

离线测试覆盖完整登录到订购闭环和异常状态，详见 `VERIFICATION.md`。官网维护、业务资格或环境验证可能使真实操作被拒绝，界面显示官方结果，不伪造成功。

## 运行与隐私

需要 Node.js 20+ 以及 Chrome；没有 Chrome 时执行 `npx playwright install chromium`。首次安装运行 `npm ci && npm run build`，再执行 `npm start`。仅监听 127.0.0.1，没有公网服务映射。

浏览器使用独立临时上下文，关闭或退出即清除会话。登录短信、本地验证码挑战、原始号码、Cookie 和订购短信 UUID 只保存在内存；订单文件仅保存脱敏号码、业务名称、结果和本地记录号。`.local/account-key` 和 `.local/orders.json` 是运行数据，不应提交或分享。迁移记录时需同时保留二者，避免破坏重复订购保护。

提交前持久化订购意图；响应丢失或服务中断后显示“结果待核查”，不会自动再订。先核查权益，只有向官方确认原请求未生效后才手动解除拦截。

## 开发命令

- `npm run check`：单元/API 测试与生产构建。
- `npm run test:ui`：自动启动独立离线夹具，验证登录、订购、查询及桌面/手机界面；不会连接官方服务，截图保存在系统临时目录。
- `npm run dev`：前端开发；后端设置 `DEV_ORIGIN=http://127.0.0.1:5173` 后另行启动。
